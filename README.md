# Hospital Sentinela — versão ampliada

## Contas de demonstração
- admin / 123 → Administração
- atendimento / 123 → Recepção
- triagem / 123 → Enfermagem
- medico / 123 → Médico
- medico2 / 123 → Médico
- farmacia / 123 → Farmácia

## Novidades
- Controle de ponto por usuário, com horário informado e horário do registro.
- Troca de usuário/encerramento de sessão.
- Dashboard administrativo com frequência, indicadores e auditoria.
- Farmácia com estoque, entradas, saídas, alertas e histórico.
- Histórico básico do paciente no painel médico.
- TV com conteúdo informativo entre chamadas.

> Projeto demonstrativo escolar. As regras de triagem são simplificadas e não substituem protocolos clínicos reais.
